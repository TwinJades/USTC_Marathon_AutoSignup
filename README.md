# 科大马拉松监测与自动报名程序

## 🏃 项目介绍

在 Windows 上检查科大马拉松是否有空余名额，按照你选择的比赛顺序自动报名。取得名额后立即填写参赛资料，核实一场比赛报名成功后停止监测。

程序使用电脑已有的 Chrome 或 Edge。登录状态、报名资料和记录保存在程序所在文件夹，密码保存在 Windows 凭据管理器。

## 📥 如何下载

打开 [下载页面](https://github.com/TwinJades/USTC_Marathon_AutoSignup/releases)，下载最新版本的 Windows ZIP 文件，解压到你方便找到的文件夹。本机需要安装 Chrome 或 Edge。

双击 `ustc-marathon.exe` 打开中文菜单。保留解压后的文件，完整卸载需要其中的卸载脚本。无需安装 Go 或其他开发工具。

## ⚙️ 如何使用

首次使用进入“设置”，按照菜单顺序完成：

1. **登录**：选择浏览器，输入账号和密码。程序自动登录并验证账户，成功后保存密码。已有有效登录状态时直接使用；验证码等需要本人在浏览器窗口完成。
2. **选择比赛及优先级**：勾选需要监测的比赛，设置优先顺序。
3. **填写信息**：填写用户类型、衣服尺码、身份证号、手机号码和紧急联系人电话。学院和性别使用网站预填值，无需填写。合法内容会保存，非法内容保留原值并显示原因；资料没有通过完整验证时禁止报名。
4. **时间设置**：根据需要调整下表中的等待时间。
5. **只读验证**：检查比赛状态、账户及报名资料，不提交报名。

| 时间设置 | 含义 |
| --- | --- |
| 检查间隔 | 每轮全部目标检查完成后的等待时间，默认 30 秒。实际两轮之间还包含网站查询耗时，因此日志间隔可能超过设置值。 |
| 请求超时 | 一次查询或页面操作的最长等待时间，默认 30 秒。普通查询超时会终止监测。 |
| 登录超时 | 等待登录完成的时间上限，默认 600 秒，包括本人完成验证码等验证的等待时间。 |

三个时间均支持正数和小数。完成设置后，在主菜单选择 **“开始监测与自动报名”**。网站认证失效时重新登录，普通监测查询复用已有登录状态。

第一步会等待完整的十秒报名须知，保留网站预填的院系和班级，填写手机号码。取得名额后立即完成第二步，两个步骤使用同一个手机号码。提交结果不明确时，程序先查询网站报名记录核实；无法确认时停止监测并保留待核查记录，重新启动时优先核查这些记录。

按 `Ctrl+C` 停止当前监测。操作完成或出现错误后，按回车返回菜单。“查看报名记录”实时查询网站，显示每场比赛是否已报名、资料是否保存，并注明本地待核查阶段。时间按本机时区显示为 `2026-10-11 14:47:50`。“存储与卸载”可以查看空间、清理缓存或全部卸载。缓存清理保留登录状态和报名记录；全部卸载清除本项目当前账户的凭据，并将运行文件夹移入回收站。回收站中的文件仍然占用磁盘空间。

请保管 `config.toml` 和 `runtime`，其中含有私人资料与认证数据。升级时保留这些文件。许可证位于发布包的 `docs/`。命令行、构建和测试说明见仓库 [开发说明](https://github.com/TwinJades/USTC_Marathon_AutoSignup/blob/main/docs/DEVELOPMENT.md)，实际验证范围见 [验收记录](https://github.com/TwinJades/USTC_Marathon_AutoSignup/blob/main/docs/VERIFICATION.md)。
