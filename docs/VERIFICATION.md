# Go 版本验证记录

验证日期：2026-10-10。程序 2.0.2；Windows x64；Go 1.27.2；本机 Chrome 155、Edge 154。

## 已验证

- `go mod verify`、本地测试与 `go vet` 通过。直接依赖版本固定在 `go.mod`，全部模块校验记录在 `go.sum`。
- 中文路径中的配置读写、保留注释、目标顺序、自定义正数与小数间隔、超大有限正数间隔、缺失资料和未知字段拒绝通过。
- 实际 SQLite 阶段持久保存、账户摘要与账户隔离通过；实际第二进程在持锁期间无法启动，锁释放后能够启动。
- Windows 凭据管理器真实存取和 UTF-16 编码通过；现有科大凭据实际完成登录，账号与网站返回一致。
- 真实终端中的浏览器选择及配置保存通过，使用独立测试配置。
- 本机 Chrome、Edge 的登录窗口、后台会话复用和真实网页查询通过；退出后结束程序浏览器上下文。
- 真实马拉松列表包含两场比赛；分别以每页一条读取，核实分页完整性。
- 本人记录查询返回 96 条；以每页 25 条读取，核实分页结果一致。
- 两场真实比赛详情均返回 `peopleNum = 1800`、`applyNum = 1800`；参与人数接口 `registrationNum = 1800`；详情页面的“报名人数限制”和“项目参与”显示一致。
- 两场比赛均处于报名期间；`applyStatus = 26`、`booleanRegistration = 0`，本人记录中没有这两场比赛。正常页面报名按钮能够识别，比赛组件的编号、名称和校区核查通过。
- 第一阶段选项接口包含院系、班级和手机；两场比赛的预填院系与班级均非空。
- 真实点击“报名”，从须知出现后完整等待至少十秒；确认按钮可用后点击，等待网站异步载入第一阶段表单；保留院系和班级，填写并核实配置手机号码。此项没有点击最终“确定”，报名提交请求数量为零，本人记录保持原值。
- 实际 `watch` 完成一轮两场满额检查，停止信号结束等待，实际提交阶段记录保持原值。此项使用独立私人测试配置，检查间隔为 0.25 秒。
- 干净中文解压目录中实际运行 EXE 帮助、浏览器列表、状态和空配置检查通过。压缩包包含 EXE、配置示例、用户 README、启动与卸载文件、运行目录标识，以及 `docs/LICENSE`、`docs/THIRD_PARTY_LICENSES.txt`。开发说明和验收记录保留在仓库，发布包与 release 目录没有 SHA256 文件。
- 源码、脚本、文档与发布文件分别位于 `src`、`scripts`、`docs` 和 `release`。迁移在原单实例锁保护下完成；原监测进程通过正常中断停止，私人配置、SQLite 与浏览器认证数据迁入发布目录。
- 实际无参数 EXE 进入五项中文主菜单；设置与存储子菜单的内容、顺序和返回入口通过。实际登录成功与操作错误均只显示一次“按回车返回菜单”，回车后正常返回原菜单。
- 实际配置逐项保存验证通过：有效尺码及紧急联系人号码保存，非法手机号码保留原值，不完整资料禁止报名，配置注释保留。学院及性别不再由填写信息表单输入。
- 真实网站 `myInfo` 返回的 `deptName` 和 `sexName` 验证有效，登录后作为预填学院与性别使用。真实网站前端 `addInfo` 对这两个字段的赋值逻辑一致，第二步代码保留并核对页面预填值。
- 使用空白独立浏览器目录与本机真实已保存凭据，完成正常统一认证、账户核查和预填资料验证；原有凭据与生产会话保留。既有会话的菜单登录及后台复用通过。
- 使用真实 Windows 终端与独立空白配置，首次选择浏览器，账号和密码各输入一次；实际完成自动认证，验证成功后保存 Windows 凭据、账户与网站预填资料。密码未出现在终端输出中，认证输出仅在内存中核查。
- 实际菜单启动真实监测，两场比赛仍为 1800/1800；发送 Ctrl+C 后结束监测、关闭浏览器、清理缓存并返回菜单。
- 实际 Windows 回收站缓存清理通过，范围外目录拒绝，认证文件保留。Chrome、Edge 分别完成真实登录与后台会话复用，退出后可清理缓存清单为空。
- 独立中文发布目录中实际启动 EXE 卸载通过，发布目录进入回收站，真实测试凭据删除；另一进程持锁时卸载拒绝。卸载过程使用标记阻止新实例启动，释放文件锁后执行回收操作。
- 卸载脚本实测移入回收站 13.76 MiB，磁盘可用空间变化为 0 MiB；回收站仍保存文件。

真实浏览器只读验收的请求超时为 90 秒。程序默认请求超时为 30 秒，可通过 `request_timeout_seconds` 调整。

## 存储测量

发布 EXE 实测 13.74 MiB，ZIP 为 5.73 MiB。发布包共八个文件，许可证位于 `docs/`；没有打包私人配置、认证会话、报名数据库或验收文档。

初次目录核查为 92.53 MiB。执行实际缓存清理时，运行数据为 92.40 MiB，其中 78.37 MiB 进入回收站；清理后为 14.03 MiB。真实浏览器重复运行、菜单与卸载测试结束后，将下载及独立测试产物移入回收站。正式运行数据实测为 6.87 MiB，其中浏览器认证与必要设置为 6.81 MiB，可清理缓存为 0.00 MiB。私人配置、脱敏记录和 SQLite 保留。文件在回收站内继续占用磁盘空间。
